# Телеграм-парсер

Задача: по расписанию забирать свежие посты из публичных телеграм-каналов (config/channels.yaml, веб-версия t.me/s/<канал>), оценивать их и отдавать лучшие Видео-мейкеру.

## Критерии отбора
- необычная или вирусная новость;
- понятна без контекста;
- помещается в ролик 15-30 секунд;
- есть визуальный образ для картинок и мемов.
Слабые посты отбрасываем. Одну новость дважды не берём (дедупликация по ссылке на источник).

## Поля карточки (общая Google-таблица)
заголовок, суть (2-3 предложения), ссылка на источник, канал-источник, дата, тематика, тон (смешной / шокирующий / познавательный), хук, идеи мемов, оценка, статус.

## Статус
Парсер ставит «новость». Дальше статус двигают Видео-мейкер и Менеджер.
