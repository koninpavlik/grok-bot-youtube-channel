# grok-bot-youtube-channel

Автоматизированный пайплайн YouTube Shorts из новостей телеграм-каналов.
Три агента (Грок-боты): **Телеграм-парсер -> Видео-мейкер -> Менеджер ютуб-канала**.
Репозиторий хранит всё, чтобы пересоздать процесс на другом боте или другой нейросети за минуты.

## Быстрый старт на новом боте
1. Создайте трёх агентов и дайте каждому его файл из `agents/` как инструкцию.
2. Подключите Google Drive/Docs/Sheets и этот репозиторий.
3. Заполните `config/channels.yaml` (каналы, расписание, тематика).
4. Создайте общую Google-таблицу по `docs/card-template.md` и впишите её ссылку в `config/links.yaml`.
5. Создайте расписания: парсер по `config/channels.yaml`, публикация по расписанию из `agents/youtube-manager.md`.
6. Выдайте менеджеру доступ к YouTube-каналу (вход делает владелец сам).

## Структура
- `agents/` - инструкции для каждого агента (источник правды).
- `config/` - каналы, расписание, ссылки на Google-файлы.
- `docs/` - процесс, шаблон карточки, маскот, аналитика, журнал решений.
- `assets/mascot/` - референсы и промпты маскота.
- `videos/<дата>-<слаг>/` - артефакты каждого ролика (сценарий, промпты, метаданные).

Подробности: `docs/process.md`, `docs/repo-guide.md`.
