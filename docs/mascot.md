# Маскот
Выбран: кот-репортёр в мятом плаще с микрофоном, «всегда в курсе». Запасной вариант: енот-сплетник.
Другие идеи: робот-попугай, сова в наушниках, лампочка с антенной.
Имя и палитра: ждём решения пользователя.
Референс-лист (6-8 поз: удивление, ехидство, шок, «подпишись») и промпты лежат в `assets/mascot/`.
