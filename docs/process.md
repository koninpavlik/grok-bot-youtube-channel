# Процесс

1. **Парсер** по расписанию читает публичные каналы (t.me/s/<канал>), отбирает новости по критериям из `agents/telegram-parser.md`, добавляет карточку в таблицу со статусом «новость».
2. **Видео-мейкер** берёт карточку, ставит «в работе», делает сценарий, картинки, озвучку, монтаж 9:16 до 30 сек, превью; статус «готово».
3. **Менеджер** готовит описание, теги, закреплённый комментарий, публикует по расписанию, ставит «опубликовано» и ссылку.

Статусы: новость -> в работе -> готово -> опубликовано (допустимо также «отклонено» с причиной).
Дедупликация: по ссылке на источник.
Лимит: не более 2 видео в день, пока нет статистики.

## Открытые вопросы (отметить решение в docs/decisions.md)
- язык и голос озвучки;
- имя и палитра маскота;
- список каналов и расписание.
