# Как вести репозиторий
- Ветка `main` - актуальное состояние. Мелкие правки коммитим напрямую, крупные изменения процесса через merge request.
- Сообщения коммитов: `agents: ...`, `config: ...`, `video: <слаг> ...`, `docs: ...`.
- Инструкцию агента меняем только в `agents/<имя>.md`, затем обновляем самого бота.
- Каждый ролик: папка `videos/<ГГГГ-ММ-ДД>-<слаг>/` с `script.md`, `prompts.md`, `meta.json` (ссылки на карточку, Drive, YouTube). Тяжёлые файлы (mp4, картинки) только в Drive, в репозитории ссылки.
- Секреты, токены и пароли в репозиторий не кладём.
- Решения и изменения процесса записываем в `docs/decisions.md` (дата, что решили, почему).
- Раз в неделю менеджер добавляет выводы в `docs/analytics.md`.
